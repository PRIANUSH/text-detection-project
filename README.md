# Text Detection and Extraction System

## 📌 Description

This project extracts text from images using Python and image processing techniques.

## 🚀 Features

* Detects text from images
* Applies preprocessing for better accuracy
* Converts image text into readable format
* Saves extracted text into files

## 🛠️ Tech Used

* Python
* OpenCV
* Tesseract OCR
